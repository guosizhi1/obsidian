# AI 与效率知识库

这是一个使用 Obsidian 和 Markdown 维护的公开知识库，面向 AI 初学者、开发者和希望提升知识工作效率的读者。

## 内容

知识库目前包含 25 篇原创中文笔记，分为五个主题：

1. AI 基础与提示工程
2. Agent 与自动化
3. AI 编程
4. Obsidian 与知识管理
5. 安全、评测与趋势

每篇笔记包含核心概念、操作步骤或示例、常见误区、检查清单和参考来源。图示优先使用 Mermaid，便于在 Obsidian、GitHub 和其他 Markdown 工具中继续维护。

## 开始阅读

## 使用方式

- 使用 Obsidian 打开 Vault 后，从总览页选择学习路线。
- 普通 Markdown 编辑器也可以直接阅读，但 Mermaid 和 Wiki 链接的显示效果可能不同。
- 内容会持续更新，重要结论请回到文末来源核对最新版本。
- 欢迎通过 GitHub Issue 或 Pull Request 提交事实修正和链接更新。
